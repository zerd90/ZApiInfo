## 1. 概述

ZApiInfo 是一款常驻 macOS 菜单栏的小工具，定时请求用户配置的大模型 API 用量/额度接口，把接口返回的各项信息显示在状态栏和下拉明细里。

**日费、剩余额度只是示例**，不是产品只关心的两个指标。凡是接口 JSON 里能解析到的业务字段（剩余额度、已用、日费、上传 / 输入 token、下载 / 输出 token、总 token、请求次数、RPM/TPM、到期时间、令牌名等）都必须能显示；用户再用筛选决定哪些上状态栏、哪些只放明细，并用自定义名称改成自己看懂的文案。

核心配置能力（第一期必须有）：

1. **请求 URL**
2. **API Key**
3. **显示字段筛选**（从「本次接口实际返回 + 常见字段目录」里挑）
4. **自定义字段显示名称**（如把 `prompt_tokens` 显示成「上传」）

产品不绑定单一厂商。默认按「通用 JSON 接口」工作：先发现全部可展示字段，再用常见字段别名表给出中文名；并提供 New API / OpenAI 兼容等预设，降低上手成本。

## 2. 背景与目标

### 2.1 背景

开发者日常使用多家大模型或中转网关（New API、One API、各类 OpenAI 兼容服务）。额度、日消耗往往要打开网页后台才能看到，切换成本高，也容易错过超额。

这些服务通常会提供一个返回 JSON 的用量接口，字段名不统一，但形态接近：给定 URL + Bearer Token，即可拿到额度、用量、token 进出、请求次数等。中转站后台里俗称的「上传 / 下载」，一般对应输入 token（prompt / input）和输出 token（completion / output）。

### 2.2 目标

| 编号 | 目标 | 衡量方式 |
| --- | --- | --- |
| G1 | 不打开浏览器也能看到接口给出的用量信息 | 状态栏常显用户勾选的字段；下拉明细覆盖本次返回的可展示字段 |
| G2 | 一套配置适配不同供应商 | 用户只改 URL / Key / 字段映射即可工作 |
| G3 | 状态栏信息可控、可读 | 支持字段筛选与自定义显示名；常见 key 有默认中文名 |
| G4 | 密钥与占用可接受 | Key 进钥匙串；后台轮询、低 CPU/内存 |
| G5 | 安装即用 | 菜单栏应用，无 Dock 图标；支持登录启动 |
| G6 | 不因「只做了日费/余额」漏掉其它指标 | 上传、下载、请求次数等只要出现在 JSON 中即可勾选显示 |

### 2.3 非目标（不做）

- 不替代完整账单后台（不做图表、发票、按模型明细分析）
- 不代理、不转发聊天补全请求
- 不内置各厂商网页爬虫 / 非官方 session 抓取
- 不做 Windows / iOS / 浏览器插件
- 不做多用户账号体系、云同步
- 不自动充值、不改远端额度
- 不多数据源 / 多 Profile、不阈值告警、不改 HTTP 方法与任意多组 Header
- 不解析 JSON 数组、不做 JSONPath、不历史曲线、不自动更新

## 3. 用户与场景

### 3.1 目标用户

个人开发者、独立开发者、小团队里自己管 API Key 的人。假设会配 URL 和 Token，但不一定懂 JSONPath。

### 3.2 典型场景

| 场景 | 描述 | 期望 |
| --- | --- | --- |
| 日常盯盘 | 写代码时余光看状态栏 | 一眼看到自己关心的几项，例如剩余、日费、上传、下载 |
| 看完整用量 | 点开菜单栏 | 明细里能看到接口返回的各项：额度、token 进出、请求次数等 |
| 换中转站 | 从 New API 换到另一家兼容接口 | 改 URL、Key，必要时改字段映射，不必重装 |
| 状态栏太挤 | 同时开了多个菜单栏 App | 只勾 1～2 个字段上状态栏；其余留在明细；显示名尽量短 |
| 接口字段难读 | 返回 `prompt_tokens`、`quota` 等英文 key | 默认叫「上传」「剩余」，也可改成任意名称 |
| 接口挂了 | Key 过期、网关 5xx | 状态栏有明确错误态，下拉菜单能看到原因，可手动刷新 |
| 隔夜对照 | 想看「今天花了多少 / 今天传了多少」但接口只有累计值 | 对任意数值字段做本地日切快照，得到今日增量 |

## 4. 产品范围

### 4.1 第一期（MVP）

- 单数据源：一个 URL + 一把 Key
- 定时拉取 JSON，**发现并支持显示全部可解析叶子字段**（不预置白名单卡死）
- 内置「常见字段别名表」：上传、下载、剩余、已用、请求次数等自动给中文名
- 状态栏展示用户勾选字段；下拉明细默认覆盖目录内已出现的字段
- 设置：URL、鉴权、刷新间隔、字段筛选、显示名、数字格式
- 派生指标：对任意数值字段可生成「今日增量」；可选「剩余占比」
- 预设模板：New API 令牌用量、New API 用户信息、OpenAI 兼容 Usage / Subscription、自定义
- 登录启动、开机后自动刷新
- API Key 存入 macOS 钥匙串

### 4.2 分发（当前）

- 产出可安装的 `.app`、`.zip`、`.dmg`（拖到「应用程序」）
- Apple Silicon；macOS 14+
- ad-hoc 签名；用户在系统设置里「仍要打开」
- 不做 Sparkle / Homebrew 自动更新

**明确不做：** JSON 数组（按日 `daily_usage`、按模型 `model_stats` 等）。不展平、不按下标取值、不挑「当天那一项」。用量只使用对象叶子（如 `usage.today.*`、`quota.*`）。

### 5.3 字段显示原则与常见目录

原则：**接口返回了什么，就能显示什么。** 日费、剩余额度只是示例，不能做成产品白名单。上传、下载、请求次数等只要出现在 JSON 中，就必须能被发现、改名、进明细或上状态栏。

| ID | 需求 | 优先级 |
| --- | --- | --- |
| F3.0 | 不使用「只允许显示日费/余额」这类固定白名单；未知 key 同样可勾选显示 | P0 |
| F3.0a | 内置常见字段别名表（按下表匹配路径**最后一段**，大小写不敏感）。命中则默认显示名为中文；用户改过的名称不得被后续刷新覆盖 | P0 |
| F3.0b | 协议壳字段默认不进入可选列表：`success`、`code`、`message`、`object`、`error`。设置中提供「显示协议字段」开关 | P1 |
| F3.0c | 设置页可按类别分组：额度 / Token（上传下载） / 请求 / 账户 / 其它 / 派生 | P1 |
| F3.0d | 测试连接成功后：目录内已出现的字段默认勾选「明细」；状态栏只默认勾选该预设的推荐项（通常 2～3 个）。自定义预设则明细默认全开目录命中项，状态栏默认空或按别名表里标记「适合上栏」的项 | P0 |

**常见字段别名表**（实现时可扩展，匹配的是路径末段）：

| 类别 | 常见 key | 默认显示名 | 适合上状态栏 |
| --- | --- | --- | --- |
| 额度 | `quota`、`total_available`、`remaining`、`remain_quota`、`balance` | 剩余 | 是 |
| 额度 | `used_quota`、`total_used`、`used` | 已用 | 否 |
| 额度 | `total_granted`、`total_quota`、`hard_limit_usd`、`soft_limit_usd`、`system_hard_limit_usd` | 总额 / 硬限额 / 软限额（按 key 区分） | 否 |
| 额度 | `total_usage` | 用量 | 是 |
| 额度 | `unlimited_quota` | 无限额度 | 否 |
| Token | `prompt_tokens`、`input_tokens`、`upload`、`upload_tokens` | 上传 | 是 |
| Token | `completion_tokens`、`output_tokens`、`download`、`download_tokens` | 下载 | 是 |
| Token | `total_tokens`、`token`、`tokens` | 总 Token | 否 |
| Token | `cached_tokens`、`cache_tokens` | 缓存 Token | 否 |
| Token | `reasoning_tokens`、`audio_tokens` | 推理 Token / 音频 Token | 否 |
| 请求 | `request_count`、`requests` | 请求次数 | 否 |
| 请求 | `rpm` | RPM | 否 |
| 请求 | `tpm` | TPM | 否 |
| 账户 | `name`、`token_name`、`username`、`display_name` | 名称 | 否 |
| 账户 | `group` | 分组 | 否 |
| 账户 | `expires_at`、`access_until` | 到期 | 否 |
| 派生 | `_derived.delta_today.<path>` | 今日{源显示名}（额度类源字段可叫「日费」） | 按源字段 |

同一响应里若同时存在「剩余」类和「上传/下载」类字段，明细应都能列出，不得因为做了余额就把 token 字段丢掉。

### 5.4 JSON 解析与字段发现

| ID | 需求 | 优先级 |
| --- | --- | --- |
| F3.1 | 仅接受 JSON 成功响应（按 body 是否能解析为 JSON 判断，不唯 `Content-Type` 是从）；非 JSON 视为失败 | P0 |
| F3.2 | 将 JSON 对象展平为字段路径列表。嵌套用点号，例如 `data.prompt_tokens`、`data.total_available` | P0 |
| F3.3 | 忽略数组与对象容器：只纳入 bool / number / string 叶子。数组不是产品范围，不做下标、当日项或聚合 | P0 |
| F3.4 | 字符串过长（>120 字符）默认不进入「可显示字段」，避免状态栏被撑爆；仍可在明细里查看原始 JSON | P1 |
| F3.5 | 测试连接或每次成功刷新后，更新「可用字段」列表；已勾选但本次响应中消失的字段，标记为「本次缺失」，不自动取消勾选 | P0 |
| F3.6 | 支持用户手动添加字段路径（应对偶发字段、深层字段）。路径非法或取不到值时按缺失处理 | P1 |
| F3.7 | 敏感叶子默认隐藏且不可勾选上栏：路径末段匹配 `*token*` 且值像密钥（如以 `sk-` 开头、或字段名为 `access_token`、`api_key`、`password`）。用量类 `*_tokens` 不在此列 | P0 |

路径规则（第一期）：

- 根对象字段：`total_usage`、`prompt_tokens`
- 嵌套：`data.quota`、`usage.completion_tokens`
- 不支持数组、`items[0].x`、通配符、过滤器

### 5.6 派生指标

接口常常只有累计值，没有「今天的量」。第一期允许**对任意数值字段**生成今日增量，并保留一个可选的剩余占比。日费只是「对已用额度做今日增量」的一种叫法。

| 派生字段 ID | 含义 | 计算规则 |
| --- | --- | --- |
| `_derived.delta_today.<源路径>` | 该字段的今日增量 | 本地 0 点（用户时区）记录该源字段快照；当前值 − 快照。无法解析为数字时不输出 |
| `_derived.remain_ratio` | 剩余占比 | `剩余字段 / 总额字段`。分母为 0 或无限额度时显示 `—` 或 `∞`（可配置） |

示例：源字段为 `data.prompt_tokens` → 显示名默认「今日上传」；源字段为 `data.used_quota` → 显示名默认「日费」（若用户把源显示名改成「已用」，今日增量则为「今日已用」，用户仍可改成「日费」）。

| ID | 需求 | 优先级 |
| --- | --- | --- |
| F5.1 | 每个数值可用字段均可单独打开「生成今日增量」；可同时对已用、上传、下载、请求次数等开多项 | P0 |
| F5.2 | 日切使用 Mac 系统时区的自然日；跨日第一次成功刷新时更新该字段快照 | P0 |
| F5.3 | 各源字段快照持久化，退出应用后仍有效 | P0 |
| F5.4 | 提供按字段「重置今日快照」，以及「重置全部快照」 | P1 |
| F5.5 | 可为「剩余占比」指定分子、分母路径；New API 令牌预设默认分子 `data.total_available`、分母 `data.total_granted`；用户信息预设默认分子 `data.quota`、分母可用 `data.quota + data.used_quota`（若实现成本高则第一期仅支持两个现成路径相除） | P1 |
| F5.6 | 今日增量继承源字段的 scale / 格式；计算时对**原始值**做差，再应用相同 scale | P1 |

### 5.8 刷新与缓存

| ID | 需求 | 优先级 |
| --- | --- | --- |
| F7.1 | 默认每 60 秒刷新；可设 15s / 30s / 1min / 5min / 15min | P0 |
| F7.2 | 手动「立即刷新」不受间隔限制，但 3 秒内重复点击合并为一次 | P0 |
| F7.3 | 系统睡眠结束、网络从无到有时，自动刷新一次 | P1 |
| F7.4 | 失败时指数退避（如 60s → 120s → 300s，上限 5min），成功后恢复原间隔 | P1 |
| F7.5 | 成功响应在本地缓存；失败时状态栏进入错误态，下拉面板仍展示「上次成功时间 + 上次数据」，并标注已过期 | P0 |
| F7.6 | 刷新进行中，面板显示细小进度/「刷新中」，不阻塞点击设置 | P1 |

### 5.9 错误与状态

状态栏需能区分正常 / 警告 / 错误，不依赖用户点开。

| 状态 | 菜单栏表现 | 触发 |
| --- | --- | --- |
| 未配置 | 图标 + `未配置` | URL 为空 |
| 正常 | 图标 + 已选字段文本 | 最近一次成功 |
| 过期数据 | 图标变淡或字段后加 `*` | 正在用缓存，刷新失败中 |
| 错误 | 图标 + `请求失败` 或 HTTP 码 | 连续失败且无可用缓存，或 Key 无效（401/403） |
| 刷新中 | 不闪烁清空；可在图标上做极轻旋转（可选） | 请求进行中 |

| ID | 需求 | 优先级 |
| --- | --- | --- |
| F8.1 | 401/403 明确提示「鉴权失败，请检查 API Key」 | P0 |
| F8.2 | 超时、DNS、TLS 失败有可读文案，不把系统错误原文整段塞进状态栏 | P0 |
| F8.3 | 下拉面板可复制最近一次请求的：URL（不含 Key）、状态码、耗时、错误信息 | P1 |
| F8.4 | 日志不写入明文 API Key | P0 |

### 5.10 设置与数据管理

| ID | 需求 | 优先级 |
| --- | --- | --- |
| F9.1 | 独立设置窗口（非仅菜单内嵌）。从菜单栏打开时窗口置前，不被其它应用挡住 | P0 |
| F9.2 | 设置分栏或分组：数据源、展示字段（可按额度/Token/请求等分类）、刷新与格式、通用 | P0 |
| F9.3 | 修改 URL/Key 后需「保存」才生效；字段勾选可即时生效 | P1 |
| F9.4 | 「导出配置」生成 JSON（不含 Key，或 Key 用占位符） | P2 |
| F9.5 | 「导入配置」合并字段映射；Key 不覆盖除非文件里显式包含且用户确认 | P2 |
| F9.6 | 「清除本地数据」：删快照、缓存、字段映射，Key 需二次确认 | P1 |

## 6. 界面与交互

### 6.1 菜单栏

```
[图标] 剩余 $12.3 · 上传 1.2k · 下载 4.8k
```

（上栏内容完全由用户勾选决定，上例只是一种常见组合，不是写死的布局。）

- 图标使用简洁 SF Symbol（如 `chart.bar`）或 App 单色模板图，适配深色/浅色菜单栏。
- 文本使用系统菜单栏字体；过长时截断为 `…`，完整内容在下拉面板。
- 无障碍：VoiceOver 读出显示名 + 数值，而不是原始 key。

### 6.2 下拉面板

自上而下：

1. **摘要区**：与状态栏相同的字段，字号更大，便于扫读
2. **明细列表**：所有勾选「明细」的字段（额度、上传、下载、请求次数等），左显示名、右当前值；缺失显示 `—`；字段较多时按类别分组或允许滚动
3. **元信息**：上次成功刷新时间、下次刷新倒计时（可选）
4. **操作**：刷新、设置、退出
5. **错误条**（若有）：一行原因 + 「重试」

第一期用原生菜单（`NSMenu` / `MenuBarExtra` 默认菜单样式）即可；若字段很多再改为 window 样式 Popover。明细超过 12 行时允许滚动。

### 6.3 设置窗口

建议宽度约 560～640pt，高度自适应，最小 macOS 14 视觉规范。

**数据源**

- 预设模板
- URL
- API Key
- 测试连接（结果区：成功字段数 / 失败原因）
- 刷新间隔、超时

**展示字段**

- 表格（可按类别分组）：启用明细、上状态栏、路径、显示名、格式、换算系数、生成今日增量
- 剩余占比的分子/分母
- 拖拽排序
- 分隔符、缩写开关、货币符号
- 显示协议字段、全选明细

**通用**

- 登录时启动
- 打开配置目录 / 清除本地数据
- 关于（版本号）

### 6.4 空态与首次使用

1. 安装后菜单栏出现「未配置」
2. 点击 → 打开设置，聚焦 URL
3. 选预设或粘贴完整 URL，填 Key，点「测试连接」
4. 成功后列出本次发现的全部字段，套用中文别名；明细默认勾选目录内字段（含上传/下载/请求次数等实际存在的项），状态栏仅勾选预设推荐项
5. 用户可改勾选与显示名，保存后状态栏开始显示

## 7. 数据模型

### 7.1 配置（UserDefaults + Keychain）

```text
AppConfig
  endpointURL: String
  authScheme: "bearer" | "none"          // 第一期
  extraHeaderName: String?               // 如 New-Api-User
  extraHeaderValue: String?
  refreshIntervalSec: Int                // 默认 60
  timeoutSec: Int                        // 默认 10
  presetId: String                       // custom | newapi_token | newapi_user | openai_usage | openai_subscription
  statusBarSeparator: String             // 默认 " · "
  compactLargeNumbers: Bool
  currencySymbol: String
  launchAtLogin: Bool
  showProtocolFields: Bool
  fields: [FieldConfig]
  remainNumeratorPath: String?
  remainDenominatorPath: String?

FieldConfig
  path: String                           // data.quota 或 _derived.delta_today.data.used_quota
  displayName: String
  showInStatusBar: Bool
  showInMenu: Bool
  generateDeltaToday: Bool               // 数值字段可开
  format: auto | integer | decimal | percent | currency | datetime
  decimalPlaces: Int
  scale: Double                          // 显示前乘以该系数，默认 1
  sortOrder: Int
  category: quota | token | request | account | derived | other
```

- `API Key` **只写入钥匙串**，不进 UserDefaults、不进导出文件默认内容。
- 钥匙串账号名与服务名固定且文档化，便于重装后识别（同一签名下可恢复）。

### 7.2 运行时状态

```text
RuntimeState
  lastSuccessAt: Date?
  lastError: AppError?
  lastRawJSON: Data?                     // 仅内存或短时缓存，不长期打日志
  values: [path: DisplayValue]
  dailySnapshots: [{
    sourcePath: String
    date: "YYYY-MM-DD"                   // 本地日历日
    rawValue: Double                     // 换算前
  }]
```

### 7.3 预设字段映射（默认）

说明：下表是「该预设下推荐勾选 / 默认名」。实际响应里多出来的字段（例如某网关在 `data` 里加了 `prompt_tokens`）仍必须出现在字段列表中，并尽量套别名表。

**New API 令牌用量** — 路径建议 `{host}/api/usage/token`

| 路径 | 默认显示名 | 状态栏 | 明细 | 备注 |
| --- | --- | --- | --- | --- |
| `data.total_available` | 剩余 | 是 | 是 | 可按网关配额系数换算 |
| `_derived.delta_today.data.total_used` | 日费 | 是 | 是 | 源字段 `data.total_used` |
| `data.total_used` | 已用 | 否 | 是 | |
| `data.total_granted` | 总额 | 否 | 是 | |
| `data.unlimited_quota` | 无限额度 | 否 | 是 | |
| `data.name` | 令牌 | 否 | 是 | |
| `data.expires_at` | 到期 | 否 | 是 | 可选 datetime |
| `_derived.remain_ratio` | 剩余% | 否 | 否 | 可选 |

参考响应见 New API `GET /api/usage/token`（`total_granted` / `total_used` / `total_available` 等）。若站点在同接口增补了 token 进出字段，按别名表显示为上传/下载。

**New API 用户信息** — 路径建议 `{host}/api/user/self`（部分站点需要额外头 `New-Api-User`）

| 路径 | 默认显示名 | 状态栏 | 明细 | 备注 |
| --- | --- | --- | --- | --- |
| `data.quota` | 剩余 | 是 | 是 | 常为内部点数，默认 scale `1/500000` 作美元时可改 |
| `data.used_quota` | 已用 | 否 | 是 | |
| `_derived.delta_today.data.used_quota` | 日费 | 是 | 是 | |
| `data.request_count` | 请求次数 | 否 | 是 | |
| `_derived.delta_today.data.request_count` | 今日请求 | 否 | 是 | 可选默认开 |
| `data.username` / `data.display_name` | 名称 | 否 | 是 | 有哪个用哪个 |
| `data.group` | 分组 | 否 | 是 | |


**OpenAI 兼容 Usage** — 路径建议 `{host}/v1/dashboard/billing/usage`

| `total_usage` | 用量 | 是 | 是 | 常见单位 0.01 USD，默认 scale=0.01 |

**带上传/下载的自定义用量 JSON（示例，非绑定厂商）**

只要响应里出现这些叶子，就必须能显示（别名表自动命名）：

```json

  "data": {
    "quota": 12.5,
    "prompt_tokens": 102400,
    "completion_tokens": 40960,
    "total_tokens": 143360,
    "request_count": 88
  }
```

| 路径 | 默认显示名 | 状态栏（建议） | 明细 |

## 11. 验收标准（MVP）

完成以下即可认为第一期可交付：

1. 未配置时状态栏提示「未配置」，点击能打开设置。
2. 填入任意返回 JSON 的用量 URL 与 Key，测试连接成功后，设置页能列出**本次响应的全部可展示叶子字段**，不能只出现日费/余额两项。
3. 若 JSON 含 `prompt_tokens` / `completion_tokens`（或 `upload` / `download`），默认显示名分别为「上传」「下载」，可勾选进明细和状态栏。
4. 若 JSON 含 `request_count`、`quota` / `used_quota` 等目录字段，同样能显示，且默认中文名正确。
5. 目录外的未知数字/字符串字段也能勾选显示，并可改成自定义名称。
6. 可将任意两项放到状态栏、其余留在明细；取消勾选后状态栏立即不再显示该项。
7. 可对「已用」「上传」「下载」同时打开今日增量，跨日后分别按快照计算。
8. 断开网络或改成错误 Key：状态栏进入失败/过期态，面板有原因，Key 未出现在可见日志。
9. 重启 App 后：URL、字段勾选、显示名、各字段日切快照仍在；Key 仍可用（同一把钥匙串）。
10. 退出菜单可退出；无 Dock 常驻图标。

## 14. 术语

| 术语 | 含义 |
